## ノーコードでできないこと

ノーコードでできないことは、**高度なロジック・アルゴリズム、 大規模データ処理・リアルタイム通信、 プラットフォーム固有機能、 高度な UI/UX カスタマイズ、 パフォーマンス最適化**です。

### 高度なロジック・アルゴリズム

**ノーコードでは独自の計算ロジックや AI の細かなチューニングは実装できません。**
ノーコードツールはテンプレート化された処理に限られます。Rabiloo が顧客向けに実装したケースでは、複雑な在庫最適化アルゴリズムをノーコードで再現できず、カスタム開発に切り替えました。

### 大規模データ処理・リアムタイム通信

**大量データの集計や高速な WebSocket 通信はツールの限界にぶつかります。**
リアルタイムダッシュボードを構築しようとした際、ノーコードは数千件のレコード処理で遅延が発生し、パフォーマンス要件を満たせませんでした。

### プラットフォーム固有機能

**iOS のネイティブ API や Android のバックグラウンド処理など、OS が提供する機能に直接アクセスできません。**
Rabiloo がモバイルアプリでプッシュ通知の細かい制御を行う必要があった際、ノーコードでは実装できず、ネイティブ開発へ移行しました。

### 高度な UI/UX カスタマイズ

**テンプレート依存のデザインで、細部までの微調整が困難です。**
ブランドガイドラインに合わせたピクセル単位のデザイン調整は、ノーコードの UI エディタでは実現できませんでした。

### パフォーマンス最適化

**コード最適化やメモリ管理はツール側に任せるため、最適な高速化が難しいです。**
アクセスが集中するキャンペーンサイトで、ページロード速度が基準を下回り、ツール側の最適化オプションだけでは改善できませんでした。
