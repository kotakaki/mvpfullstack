## 全体構造の思想

Rabilooの顧客は「システムを作りたい・外注したい日本企業の意思決定者」。
その意思決定ジャーニーは以下の3段階に分かれており、クラスターがそれぞれの段階をカバーする。

```
STAGE 1              → STAGE 2                → STAGE 3               → CV
「何をどう作るか」      「誰とどう作るか」          「ベトナム/オフショアで作る」  Rabilooに相談
[クラスターA]          [クラスターB]              [オフショアクラスター(既存)]
```

## クラスター間のリンク設計原則

```
クラスターA（技術選定）
    └── 「技術が決まったら発注の方法も知りたい」
         ↓ 内部リンク
クラスターB（発注マネジメント）
    └── 「では外注先はどこに？ベトナム開発を検討したい」
         ↓ 内部リンク
オフショアクラスター → コンバージョン（お問い合わせ）
```

### 内部リンクのルール（content-engine.mdより）

- ピラー記事への内部リンク：各記事から**最大2回**
- サポート記事への内部リンク：各記事から**1回まで**
- 同クラスター内のサポート記事同士：直接リンクは原則禁止（ピラーを経由する設計）
