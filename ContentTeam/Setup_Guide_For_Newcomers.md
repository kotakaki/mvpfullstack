# Antigravity 執筆環境セットアップ手順書

来週からチームに合流する新入社員が、AIエディタ「Antigravity」を使って記事を執筆できるようにするためのPC環境セットアップと初回テストの手順です。

---

## 🛠️ セットアップ手順

### ステップ1：GitHubへのアクセス権限の付与（※管理者用タスク）
管理者は、新入社員のGitHubアカウントを該当リポジトリ（`kotakaki/mvpfullstack`）の共同開発者（Collaborator）として招待し、アクセス権限を付与してください。
*   **招待手順**: GitHubリポジトリの `Settings` > `Collaborators` > `Add people` から招待を送ります。

### ステップ2：リポジトリのクローン
新入社員のPCでターミナル（Mac）またはコマンドプロンプト（Windows）を開き、プロジェクトのデータをローカルPCにダウンロードします。

```bash
# 作業用の任意のフォルダへ移動して実行
git clone https://github.com/kotakaki/mvpfullstack.git
```

> [!NOTE]
> PCに Git が入っていない場合は、事前に [Git公式サイト](https://git-scm.com/) 等からインストールを済ませておいてください。

### ステップ3：Antigravity（AIエディタ）のインストール
1. 社内規定のリンクより「Antigravity」のインストーラーをダウンロードし、PCにインストールします。
2. アプリを起動し、ログイン（GitHub連携など）を完了します。

### ステップ4：ワークスペースを開く
1. Antigravityのメニューから **[File] > [Open Folder...]** を選択します。
2. ステップ2でクローンした `mvpfullstack` フォルダを選択して開きます。
3. これにより、フォルダ内にあるAI執筆エンジン（`.agents/workflows/` 配下の設定ファイル）がエディタに自動で読み込まれます。

### ステップ5：スラッシュコマンドの動作確認
環境が正しくセットアップできたかをテストします。

1. エディタ内の右側（または左側）にある **AIチャットパネル** を開きます。
2. チャットの入力欄に半角で `/` と入力します。
3. 候補に以下のコマンドが表示されるか確認します。
   *   `/content-engine` (通常記事用)
   *   `/literacy-content-engine` (初学者向け記事用)
   *   `/content-engine-en` (英語記事用)
   *   `/content-engine-vi` (ベトナム語記事用)
4. チャット欄に以下のように入力し、送信します。
   ```text
   /content-engine テスト 起動確認です
   ```
5. AIが「【現在実行中のフェーズ: PHASE 0】」から始まる内容を返し、出力の最後で自動停止すればセットアップは完了です。

---

## 📚 セットアップ完了後のトレーニング資料
セットアップ完了後、新入社員の方は以下のドキュメントを順に読み、執筆ルールを理解してください。

1. **[記事制作エンジン 利用ガイド](../Rabiloo_Content_Engine_Guide.md)**
   AIと人間が協働して記事を作る「フェーズ・ゲート方式（構成と各章を人間が都度レビューする仕組み）」のルールが書かれています。
2. **[Rabiloo コンテンツ制作グローバルガイドライン](./Global_Guideline_JP.md)**
   「現場の声を重視するトーン（Rabiloo Voice）」「H2の1つ目で即答するルール（First Answer Rule）」「画像サイズ規定（Retina対応の2倍サイズ）」など、品質を保つための基準がまとめられています。
