# ナレッジ：ほねごり様インタビュー（整骨院DX・54店舗拡大の裏側）

**ソース:** [整骨院DXで54店舗・年商100億円目前——「ほねごり」の急成長を支えた伴走型パートナー戦略](https://rabiloo.co.jp/customer-stories/honegori)

この記事から抽出した、Rabilooのコンテンツ制作（特に多店舗展開・DX関連）において活用すべき重要なインサイト（一次情報）をまとめます。

---

## 1. 事業成長とシステム（なぜオーダーメイドが必要か）
- **成長企業特有の壁:** 創業時はExcelや手書きで済むが、店舗展開に伴い限界が来る。「人の力だけ」ではヒューマンエラー（現金の数え間違い等）が発生し、生産性に個人差が出る。
- **事業の変化とシステムの乖離:** 企業が成長すると、整骨院から鍼灸、さらに訪問診療など、オペレーションが変化・拡張する。
- **既製品の限界:** オペレーションが変わるたびに別々の既製品（ツール）を導入すると、現場の運用が複雑になり、一元管理ができなくなる。成長企業には、自社の変化に合わせて拡張できる「オーダーメイド（自社専用）」のシステムが必要不可欠。

## 2. DXが現場にもたらす「具体的なPainの解消」と提供システム

Rabilooがほねごり様と段階的に作ってきたシステムと、それが解決した「現場の生々しい痛み」は以下の通りです。

| システム名 | 解決した具体的な課題（Pain） | 効果（Solution） |
| :--- | :--- | :--- |
| **POSレジ・自動入金機** | 会計締め作業の手間と現金の数え間違い | 多様な支払い方法・保険・優待の自動処理。社員が現金に触れないオペレーションを実現 |
| **予約システム** | LINE経由の予約管理の限界 | Web予約で患者自身が予約可能に。受付業務を削減し、コミュニケーションの時間を創出 |
| **事前問診票** | 来院時の手書き記入による待ち時間 | Web上で事前入力。来院前に患者情報を把握し、施術準備の質を向上 |
| **デジタルサイネージ** | 店舗ごとのポスター掲示・差し替えの手間 | 本社から一括配信・自動切替。店舗数が増えても運用負荷が変わらない |
| **ほねごりスキャン** | 姿勢分析の属人化 | 撮影データから骨格・筋肉の状態を可視化。施術提案の再現性を向上 |
| **WILLMate** | 多店舗化による情報共有・教育の断絶 | 社内SNS・マニュアル・組織図・タレントマネジメントを一元化。50店舗超の組織を繋ぐインフラに |

## 3. 「誰と進めるか」〜 Rabilooが選ばれる理由（伴走型パートナーの価値）
- **当事者意識（オーナーシップ）:** Rabilooは「発注されたものを作るだけの外注」ではなく、「自社プロダクトを作るかのように、どうすればもっと良くなるかを考えてくれる」パートナーとして評価されている。
- **圧倒的な対応スピード:** 現場で発生するバグや要望に対し、日本国内のベンダーと比較しても「恐ろしく速い」スピードで対応・修正を行う。この機動力が現場のストレスを最小限に抑えている。
- **要件定義の深さ:** 阿部社長の「こうしたい」という抽象的な要望を、要件定義のプロが具体的なシステム仕様に落とし込むことができる。

## 4. コンテンツ制作・マーケティングのコア戦略

今後のコンテンツは、以下の**「POCで即効性の痛みを取り、継続契約（伴走）へ繋げる」ビジネス戦略**に基づいて制作します。

1. **今すぐ止めたい「具体的な痛み」へのフォーカス**
   - 経営者が日々直面している「現金の数え間違い」「予約のダブルブッキング」「ポスター張り替えの手間」といった、泥臭いが確実なPainを記事のフック（掴み）にする。
   - 「DX」という抽象的な言葉で売るのではなく、「このシステムを入れれば、今日の締め作業から解放される」という具体的なソリューション（POC）への引き合いを獲得する。

2. **段階的なシステム拡張の提示**
   - 最初からフルスクラッチの大規模開発を売るのではなく、「まずはこの小さな課題をPOCで解決しましょう」と提案する。
   - 「さらに機能を充実させたければ、自社の成長に合わせてRabilooとカスタマイズを進められる」というロードマップを見せる。

3. **「システムベンダー」から「伴走型パートナー」への認識転換**
   - POCで実力とスピードを証明した上で、「伴走型パートナー（継続的な開発契約）」へと引き上げるシナリオを記事内で設計する。
