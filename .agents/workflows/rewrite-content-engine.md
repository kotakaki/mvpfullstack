# Rabiloo リライト特化型 記事制作エンジン

既存記事の弱点（検索意図とのギャップ）を分析した上で、NotebookLMなどの「高度なリサーチデータ」を注入し、記事を強力に最適化（リライト）するワークフローです。

## 起動方法

`/rewrite-content-engine [対象キーワード/目的]`
※起動後、まずはAIが「直したい既存記事」の投下を求めます。

---

# ⛔ 【基本制約・システムルール】

1. **フェーズ宣言**: 出力の冒頭で必ず `【現在実行中のフェーズ: PHASE X】` と宣言すること。
2. **強制停止トリガー**: 各フェーズの最後はユーザーへの確認文で終え、直後で出力を停止すること。
3. **ステートレス原則**: ユーザーから投下された長文（既存記事やインサイト資料）は、AIが抽出・出力した「リライト方針」と「構造化抽出データ」としてチャット上に固定されます。以後の執筆フェーズでは、元の長文に遡らず、抽出された正本のみを参照して幻覚を防ぎます。
4. **抽象化・要約の厳禁**: 追加投入されるリサーチデータの美味しい情報（具体性）を丸めず、そのままの解像度で活かすこと。
5. **見出しのKW配置ルール（SEO必須）**:
   - **タイトルのKW必須**: タイトルには必ずメインKWを含める。
   - **H2:1のFirst Answer Rule（最重要）**: 最初のH2見出しには必ずメインKWを含める（例：`AIエージェントとは？〜〜`）。そしてそのH2直下の本文1行目で、読者の検索意図（＝Googleに打ち込んだ疑問）に対する直接的な定義・回答を即答すること（例：`AIエージェントとは、〜〜するシステムです。`）。アナロジーや背景説明から本文を始めるのは禁止。定義で即答→その後に補足・深掘りの順序を厳守する。
   - **H2全体のKW出現ルール**: すべてのH2にメインKWまたは関連KWを含める。KWが完全に不在のH2は検索順位に寄与しないため禁止。ただし、全H2にメインKWを無理に繰り返す必要はなく、自然な範囲で関連KWやサブKWを配置する。

## PHASE 1：既存記事の分析とリライト方針の策定

**AIのアクション:**
1. ユーザーに「直したい既存の記事（ファイルパスまたはベタ貼り）」の投下を促す。
2. 記事を受け取ったら、対象キーワードの検索意図とのギャップを分析し、「どこをどう直すべきか（リライト方針案）」を提示する。
3. 最適化に使用する「追加インサイト資料（NotebookLM等）」の投入をユーザーに促す。

**出力フォーマット:**
```text
【現在実行中のフェーズ: PHASE 1】
■ 既存記事の課題とリライト方針案
- 課題1: ...
- 解決策（方針）: ...

この方針をベースに最適化を行います。記事に注入したい「追加インサイト資料（リサーチデータ）」をファイル指定、またはここに貼り付けてください。
```
👉 **ここで完全停止（追加資料の投入を待つ）**

---

## PHASE 2：追加資料の「成分無調整」構造化抽出

インサイト資料が投下されたら、それをPHASE 1のリライト方針に合わせて抽出します。

**AIのアクション:**
提供された追加資料から、以下の4カテゴリで**具体性を一切落とさずに（要約せずに）**情報を抽出・仕分けする。
1. **[数値・ファクト]**
2. **[読者の隠れたペイン・本音]**
3. **[独自の解決策・アングル]**
4. **[キラーフレーズ]**

**出力フォーマット:**
```text
【現在実行中のフェーズ: PHASE 2】
■ 追加資料からの構造化抽出（コア・インサイト）
- [数値・ファクト]: ...
（中略）

これらの方針と追加インサイトを軸に、構成案の再構築（PHASE 3）を作成してよろしいでしょうか？
```
👉 **ここで完全停止**

---

## PHASE 3：リライト版・構成案の再構築

リライト方針と抽出したインサイトを掛け合わせ、新しいH2/H3構成を作成します。

**AIのアクション:**
- 各見出しにおいて、**「PHASE 2で抽出したどの追加データを使用するか」**を明確にマッピングした構成案を作成する。

**出力フォーマット:**
```text
【現在実行中のフェーズ: PHASE 3】
1. **タイトル案（3案）**
2. **見出し構成案（既存ベース ＋ 使用データマッピング付き）**
   ※H2:1は必ずメインKWを含み、検索意図への直球回答から始めること（First Answer Rule）。全H2にKWまたは関連KWを含めること。
   - H2: 〇〇〇〇（※新規追加 or 修正）
     - [使用データ]: [数値・ファクト]の〇〇を使用

上記の構成で、リライト執筆（PHASE 4）に進んでもよろしいでしょうか？
```
👉 **ここで完全停止**

---

## PHASE 4：インサイトを薄めない最適化執筆

構成合意後、記事のリライト（執筆）を進めます。

**AIのアクション:**
- マッピングされた追加データを確実に盛り込み、事実ベースで記事全文（ドラフト）を一括執筆する。

**出力フォーマット:**
```text
【現在実行中のフェーズ: PHASE 4】
（リライト後の本文...）

---
リライトが完了しました。修正が必要な箇所はありますか？
```
👉 **ここで完全停止**
