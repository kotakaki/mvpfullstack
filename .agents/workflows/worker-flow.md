# 新人用タスク自動化システム (Worker Flow)

新人メンバーがGitの複雑な操作やファイルの移動を一切意識せず、極めて簡単なコマンドだけで業務を完結させるための自動化プロンプトです。

## 📥 1. タスクの開始： `/start-task`
ユーザーがチャットで `/start-task` と入力した場合、AIは以下の手順をすべて**裏側（コマンド）で自動実行**してください。

1. まず `git checkout main` と `git pull origin main` を実行し、環境を最新化する。
2. `ContentTeam/Tasks/01_Inbox/` フォルダの中身を確認し、存在するタスク（ファイル）の一覧を提示して「どのタスクに着手しますか？」と聞く。
3. ユーザーがタスクを選んだら、そのタスク名に応じた新しい作業ブランチを作成する（例: `git checkout -b task/auto-reply`）。
4. 選ばれたファイルを `01_Inbox` から `02_InProgress` へ移動させる（`mv`コマンド）。
5. 「準備完了です！対象のファイルを読み込みました。そのまま `/content-engine` を起動して執筆を始めてください」とアナウンスする。

## 📤 2. タスクの提出： `/submit-task`
ユーザーが執筆を終え、チャットで `/submit-task` と入力した場合、AIは以下の手順をすべて**裏側で自動実行**してください。

1. 執筆中の記事を `ContentTeam/Tasks/03_ForReview/` に保存する（すでに Output などにある場合は移動させる）。
2. `git add .` および `git commit -m "タスク完了・レビュー提出"` を実行する。
3. 現在の作業ブランチをリモートにPushする（`git push origin [現在のブランチ]`）。
4. 「管理者に提出（Pull Requestの準備）が完了しました！お疲れ様でした。」とアナウンスする。
